# AV Music Streaming App

A modern full-stack Music Streaming Web App.

## Technology Stack

- **Frontend:** React + Vite, Tailwind CSS v4, Zustand, Framer Motion, Lucide React
- **Backend:** Node.js, Express, yt-search, @distube/ytdl-core

## Features

- **Music Search:** Search and find any song from YouTube.
- **Audio Streaming:** Play high-quality audio streams without video overhead.
- **Auto Play:** Automatically fetches related songs and adds to the queue.
- **Dark Neon UI:** Modern glassmorphism design with a dark theme (#0f172a) and neon accent color.
- **Keyboard Controls:** Press `Space` to play/pause the currently playing song.

## How to Run Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm

### 1. Start the Backend Server

```bash
cd backend
npm install
npm run start 
# or 
node server.js
```
*The backend will run on `http://localhost:5000`.*

### 2. Start the Frontend Development Server

Open a new terminal window:
```bash
cd frontend
npm install
npm run dev
```
*The frontend will run on `http://localhost:5173` (or depending on Vite's assignment).*
